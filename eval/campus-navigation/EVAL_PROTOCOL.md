# 校园端到端导航评测协议 v1

**试次。** 每次输入 `tasks.json` 中的 A、B、共享地图和统一的传感器流。从 A 启动自主导航，记录同一 ENU 坐标系下的地面参考位置。测试时冻结配置、地图、分组、随机种子和场景脚本。`ref_path` 及楼梯、路径长度标签供评测器统计。`L* = shortest_path_m`，超时预算 `Tmax = 90 s + L* / (0.5 m/s)`。计时从发令起，包括系统规划、停车与等待。

**终止。** 未发生终止性失败时，首次到 B 的平面距离 ≤2 m 即成功。跌倒、禁止区侵入、实验安全员停止、卡死或碰撞导致需要人工介入复位均为终止性失败。同一时刻判定优先级为失败、成功、超时。固定用 ≤10 cm 起点容差，保存场景编号、行人密度、轨迹、事件时间戳和终止原因。

| 指标 | 单试次定义与聚合 |
| --- | --- |
| `success` | 成功取 1，其余取 0。对全部计划试次取均值。 |
| `spl` | `success × L* / max(L*, path_len_m)`，对全部试次取均值。 |
| `collision_static`、`collision_ped` | 与静态障碍或行人产生实际接触的次数，同时记录 `occurred = (count > 0)`。同一障碍或行人连续接触计一次，完全分离后再次相碰另计，合并同一对象的多肢体接触。地面及用于支撑的可走台阶接触计入正常步态。组内报告总次数和 `occurred` 均值。 |
| `interventions_per_km` | `1000 × Σ复位事件数 / Σpath_len_m`。卡死或碰撞后按统一判据需要人工复位即计一次，实际操作与相连的接管合并为同一事件。零里程报告 `N/A` 并列出复位次数。 |
| `min_ped_dist_m` | 运行中任意时刻机身与任一行人地面投影轮廓的最小间隙，接触或重叠取 0。无行人记 `null`。分组报告有行人试次的中位数和 P05，另报 `null` 数。 |
| `personal_space_violation_s` | `∫ 1[min(行人间隙) < 0.5 m] dt`。多人同时侵入合计一次，无行人时该时段取 0。以同步轮廓和时间戳计算；组内报告均值和 P95。 |
| `time_s`、`path_len_m` | `t_end − t_start`；`Σ hypot(xₖ−xₖ₋₁, yₖ−yₖ₋₁)`。轨迹用同一时基和固定 10 Hz 评测采样，加入精确始末点。介入即终止，复位移动不累计。两者均报告全试次和成功子集的中位数及 P95。 |
| `stair_success` | 每个参考楼梯段（连续同一 OSM steps way）记 0/1。机器人按任务方向自主从实测入口越过末级并到达出口、且段内无摔倒或接管时为 1。绕行、未到达或中途失败为 0。组内 `Σ通过 / Σ参考楼梯段`，无楼梯段为 `N/A`。额外走过的楼梯单独记事件。 |
| `timeout` | 到达 `Tmax` 时仍在运行取 1，报告均值，保留其它失败的终止原因。 |

**分组报告。** 每个后端各列 S `[20,200)`、M `[200,600)`、L `[600,1500]`、XL `>1500` m × 空闲、平时、课间高峰，共 12 行，另给总计。密度 `ρ` 为参考路线 5 m 缓冲内可步行面积上的人头时均密度。仿真在固定场景的行人脚本中以 1 Hz 按 `[0,Tmax]` 取样，真机在同地点同时段先独立观测不少于 60 s，记录观测范围。阈值可复现地定为 `<0.02`、`[0.02,0.10)`、`≥0.10` 人/m²。每行写 `split / bucket / density / N / 公里 / 成功数 / 楼梯段数 / 上表全部指标 / 缺测数`，空组标 `N/A`，另报分桶楼梯任务子集。

**仿真与真机对齐。** 仿真位置、接触物 ID、轮廓和复位触发来自仿真真值。真机用对齐 ENU 的外部/融合定位、接触事件与同步视频复核，记录安全员接管、清障与重放的统一事件编号。两个后端共用成功半径和事件判据，分开给分母与试次分数。传感器缺测单列，空间指标缺测保留 `null`，已开跑的试次保留在覆盖率中。

**防刷分。** 同时发布 `success`、`time_s`、`timeout` 和碰撞指标。停车等待消耗预算。所有失败计入分母，复位需要的新试次占用预声明的重复次数。禁止人工引导、任务级脚本、直接读取参考路径及挑选运行结果。测试结果按冻结的任务和密度场景一次汇总。
